# 旅迹微信小程序

这是与 Spring Boot 网页端共享数据的原生微信小程序客户端。它不是网页 WebView，首页、地图、发布、计划、报告和个人中心均使用小程序组件实现。

## 已实现功能

- 登录与注册，共用网页端账号
- 旅行信息流、搜索、省份筛选、下拉刷新
- 足迹详情、点赞与收藏
- 图片上传、原生地图选点、无图片发布；手机原图会在本机自动优化到云端限制以内
- 全国足迹地图与个人旅行轨迹
  - 全国地图只显示公共点位，不绘制用户路线
  - 个人地图按照足迹发布时间从早到晚连接
- 行程计划创建、进度查看和删除
- 每周、每月、每年旅行报告
- 个人旅行档案
- 可视化服务器连接检测

## 导入微信开发者工具

1. 在 D 盘项目目录运行后端：

   ```powershell
   mvn spring-boot:run
   ```

2. 打开微信开发者工具，选择“导入项目”。
3. 项目目录选择：`D:\codex project\shujujiegoukeshe\miniapp`。
4. 本地开发时，在“本地设置”中关闭“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
5. 编译后进入“我的 → 连接设置”，点击“保存并检测连接”。

## 开发者工具与真机地址

- 开发者工具：`http://127.0.0.1:8080`
- 当前电脑 WLAN 示例：`http://192.168.43.15:8080`
- 真机必须与电脑处于同一 Wi-Fi/热点网络；如果电脑 IP 变化，请在“连接设置”中更新。
- Windows 防火墙需允许 Java 在当前网络访问。

## 正式发布前

- 使用自己的正式微信小程序 AppID 替换 `project.config.json` 中的开发 AppID。
- 将 Spring Boot 后端部署到可公网访问的 HTTPS 域名。
- 在微信公众平台配置 `request` 和 `uploadFile` 合法域名。
- 在小程序后台完成用户隐私保护指引，声明位置选择用途。
- 若需要微信一键登录，需要在后端新增 `wx.login` code 换取 OpenID、账号绑定与密钥环境变量；不要把 AppSecret 写入小程序代码。

## Back4app 临时环境说明

- 在“我的 → 连接设置”中填写当前 Back4app 的完整 HTTPS 地址，无需连接电脑或局域网。
- 小程序登录令牌只以 SHA-256 哈希保存到数据库，默认有效期 30 天；Back4app 重启或重新部署后不再强制退出登录。
- Back4app 免费临时域名变化后，需要在连接设置中替换新地址；域名变化会被视为新服务器，微信正式发布仍需要固定合法域名。

## 目录结构

- `pages/feed`：旅行首页
- `pages/map`：原生足迹地图
- `pages/publish`：发布足迹
- `pages/plans`：行程计划
- `pages/report`：周/月/年报告
- `pages/mine`：个人中心
- `pages/server`：连接设置
- `utils/request.js`：统一请求、上传、登录态与服务器地址管理
